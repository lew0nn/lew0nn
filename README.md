## I make instruments for controlled damage.

I'm **lewonn**. I build audio software where signal processing, interaction design, and slightly unreasonable ideas meet. Most of my current work lives in C++ and turns complicated machinery into something you can actually play.

```text
source material  →  analysis  →  deliberate instability  →  usable control
```

### Operating principles

- The source should change the behavior, not just feed it.
- Complexity belongs inside the engine; intent belongs on the surface.
- An interface should explain the sound before the manual has to.
- Strange is good. Uncontrolled is merely unfinished.
